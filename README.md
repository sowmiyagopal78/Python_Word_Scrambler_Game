# Word Unscramble Game 🔤

A simple, interactive command-line Python game where players test their vocabulary and word-solving skills by unscrambling randomized words.

---

## 📝 About the Project

The **Word Unscramble Game** presents players with a scrambled word selected at random from a predefined list. The goal is simple: decipher the scrambled letters and guess the correct original word. 

### Key Features
* **Option to Play or Skip:** Gives users the choice to start the game immediately or exit gracefully.
* **Randomized Word Selection:** Picks a random word each round to keep the gameplay unpredictable.
* **Letter Shuffling:** Shuffles the sequence of letters dynamically for each word.
* **Instant Feedback:** Displays whether the guess was correct or reveals the right answer if incorrect.

---

## 🚀 How to Run

1. Make sure you have **Python 3** installed on your system.
2. Clone this repository or download the source code file.
3. Open your terminal or command prompt and run:

```bash
python main.py
```

---

## 🎮 How to Play

1. Run the program in your terminal.
2. Enter `Guess` to play or `Skip` to exit.
3. If you choose to play, inspect the uppercase scrambled word displayed on the screen.
4. Type in your answer and press `Enter` to see if you got it right!
